# Dashboard deportivo con Streamlit

## Descripción

Esta aplicación web interactiva muestra el rendimiento y las estadisticas clave (goles y asistencias) de los jugadores del equiopo de futbol de la facultad de datos de la universidad santo tomas utilizando datos simulados.

## Tecnologias utilizas

- **streamlit**
- **pandas**
- **python**

## Instalacion

Abrir el terminal de vs en la carpeta del proyecto e instalar las dependencias necesarias ejecutando:

pip install streamlit pandas
